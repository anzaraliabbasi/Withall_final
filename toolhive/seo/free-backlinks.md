# Free Backlinks Checklist (do once, then maintain)

Launch week:
- [ ] Google Search Console + Bing Webmaster Tools (both free, both index)
- [ ] Crunchbase / Product Hunt page (launch post: "free 117-tool toolbox, 100% client-side")
- [ ] AlternativeTo entries: list ToolHive as alternative to the big paid tool suites
- [ ] G2 / Capterra free listings (slow but durable links)
- [ ] Hacker News "Show HN" post (one shot, do it with the real launch + demo GIF)
- [ ] Dev.to / Hashnode write-up: "how we run 117 tools with zero backend" — technical, linkable
- [ ] GitHub: open-source one useful snippet or the gen-registry script with a site link
- [ ] Free tool directories: check each is real + indexed before submitting (no link farms)

Ongoing monthly (15 min):
- [ ] 2 new directory/profile links max (quality over volume)
- [ ] Skyscraper: find competitor directory links (free Ahrefs Webmaster Tools on their site),
      get listed in the same real ones
- [ ] Repair broken backlinks: GSC → Links → top sites; if any 404, restore or redirect
- [ ] Convert one unlinked brand mention (search "toolhive" monthly) into a link — just ask

Never:
- [ ] Buy links, exchange sitewide links, or use PBNs — penalties cost more than the links earn.
